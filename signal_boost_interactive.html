Βελτίωσε το σήμα & το Wi-Fi σου

Επίλεξε συσκευή, δες τα βήματα, δοκίμασε κι άλλα κόλπα — όλα σε ένα μέρος.

1
Σύρε από πάνω προς τα κάτω για να ανοίξεις το γρήγορο μενού ρυθμίσεων.
2
Πάτησε το εικονίδιο Λειτουργία Πτήσης για να την ενεργοποιήσεις. Περίμενε 5–7 δευτερόλεπτα
3
Πάτησε ξανά για να απενεργοποιήσεις τη Λειτουργία Πτήσης. Αυτόματη επανασύνδεση
1
Σύρε από την επάνω δεξιά γωνία για να ανοίξεις το Κέντρο Ελέγχου.
2
Πάτησε το εικονίδιο Λειτουργία Πτήσης. Περίμενε 5–7 δευτερόλεπτα

Το κινητό μπορεί να μείνει «κολλημένο» σε αδύναμη κεραία ακόμα κι αν υπάρχει καλύτερη. Η Λειτουργία Πτήσης αναγκάζει πλήρη αποσύνδεση — και το κινητό επιλέγει αυτόματα το βέλτιστο δίκτυο.

Αλλαγή DNS

  • Πήγαινε Ρυθμίσεις → Wi-Fi → Πάτησε και κράτα το δίκτυό σου
  • Επίλεξε «Τροποποίηση δικτύου» και μετά «Σύνθετες επιλογές»
  • Άλλαξε IP σε «Στατική» και συμπλήρωσε DNS 1: 1.1.1.1 (Cloudflare) ή 8.8.8.8 (Google)
  • Αποθήκευσε και επανασύνδεσε. Ταχύτερος χρόνος απόκρισης ιστοσελίδων!

2.4 GHz vs 5 GHz

  • 2.4 GHz: Μεγαλύτερη εμβέλεια, περνά τοίχους — ιδανικό αν είσαι μακριά από τον router
  • 5 GHz: Πολύ γρηγορότερο αλλά μικρότερη εμβέλεια — ιδανικό κοντά στον router
  • Αν ο router σου έχει και τις δύο ζώνες, επίλεξε χειροκίνητα ανάλογα με τη θέση σου

Καθαρισμός cache δικτύου

  • Android: Ρυθμίσεις → Εφαρμογές → Επιλογή εφαρμογής → Αποθηκευτικός χώρος → Εκκαθάριση cache
  • iPhone: Ρυθμίσεις → Γενικά → Αποθήκευση iPhone → Επιλογή εφαρμογής → Εκφόρτωση εφαρμογής
  • Για πλήρη επαναφορά ρυθμίσεων δικτύου: Ρυθμίσεις → Γενικά → Μεταφορά/Επαναφορά → Επαναφορά ρυθμίσεων δικτύου

Εφαρμογές φόντου

  • Android: Ρυθμίσεις → Μπαταρία → Χρήση μπαταρίας → Περιορισμός εφαρμογών φόντου
  • iPhone: Ρυθμίσεις → Γενικά → Ανανέωση εφαρμογής στο παρασκήνιο → Απενεργοποίηση
  • Αυτό ελευθερώνει εύρος ζώνης για τις εφαρμογές που χρησιμοποιείς ενεργά
