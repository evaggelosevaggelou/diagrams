Αλλαγή DNS
Ρυθμίσεις → Wi-Fi → Πάτησε και κράτα το δίκτυό σου
Επίλεξε «Τροποποίηση δικτύου» → «Σύνθετες επιλογές»
Άλλαξε IP σε «Στατική» και συμπλήρωσε DNS: 1.1.1.1 (Cloudflare) ή 8.8.8.8 (Google)
Αποθήκευσε και επανασύνδεσε. Ταχύτερος χρόνος απόκρισης!
2.4 GHz vs 5 GHz
2.4 GHz: Μεγαλύτερη εμβέλεια, περνά τοίχους — ιδανικό μακριά από τον router
5 GHz: Πολύ γρηγορότερο αλλά μικρότερη εμβέλεια — ιδανικό κοντά στον router
Αν ο router έχει και τις δύο ζώνες, επίλεξε χειροκίνητα ανάλογα με τη θέση σου
Καθαρισμός cache δικτύου
Android: Ρυθμίσεις → Εφαρμογές → Επιλογή εφαρμογής → Αποθηκευτικός χώρος → Εκκαθάριση cache
iPhone: Ρυθμίσεις → Γενικά → Αποθήκευση iPhone → Εκφόρτωση εφαρμογής
Για πλήρη επαναφορά: Ρυθμίσεις → Γενικά → Επαναφορά ρυθμίσεων δικτύου
Εφαρμογές φόντου
Android: Ρυθμίσεις → Μπαταρία → Χρήση μπαταρίας → Περιορισμός εφαρμογών φόντου
iPhone: Ρυθμίσεις → Γενικά → Ανανέωση εφαρμογής στο παρασκήνιο → Απενεργοποίηση
Ελευθερώνει εύρος ζώνης για τις εφαρμογές που χρησιμοποιείς ενεργά
